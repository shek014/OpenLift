# OpenLift

A free and open-source workout tracker for Android.

> Early development. The app currently has its navigation and placeholder screens.

## Planned features

- **Workout logging**: sets, reps, weight and a rest timer
- **Exercise library**: every exercise linked to the muscles it works, shown on a body map
- **Routines**: build your own, or start from ready-made splits (Upper/Lower, Push/Pull/Legs, Full Body and more)
- **History and graphs**: overall training volume over time and progress for each exercise

## Built with

Kotlin, Jetpack Compose and Material 3. Minimum Android version: 8.0 (API 26).

## Building

1. Install [Android Studio](https://developer.android.com/studio).
2. Open this folder in Android Studio (File > Open) and wait for the Gradle sync to finish.
3. Connect an Android phone with USB debugging turned on, or create an emulator in Device Manager.
4. Press Run.
